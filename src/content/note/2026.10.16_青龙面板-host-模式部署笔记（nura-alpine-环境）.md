\# 青龙面板 Host 模式部署笔记（Alpine / Debian 通用）



\## 一、环境背景



\- \*\*系统\*\*：Nura（基于 Alpine Linux）/ Debian / Ubuntu

\- \*\*服务管理\*\*：OpenRC（Alpine 系）或 systemd（Debian 系）

\- \*\*部署方式\*\*：Docker + host 网络模式

\- \*\*目标\*\*：一键部署青龙面板（whyour/qinglong）



\---



\## 二、踩坑记录



\### 问题 1：拉取镜像报 403 Forbidden



\`\``

failed to copy: httpReadSeeker: failed open:

unexpected status from GET request to

https://docker.xuanyuan.me/v2/whyour/qinglong/blobs/...: 403 Forbidden

\`\``



\*\*原因\*\*：镜像加速源 \`docker.xuanyuan.me\` 拒绝访问（限流或故障）。



\*\*次要问题\*\*：\`docker.1ms.run\` 也报 \`Host doesn't match\` 警告，协议不兼容。



\*\*结论\*\*：这两个源都不适合当前环境，直接从 \`daemon.json\` 中剔除。



\---



\### 问题 2：\`docker ps\` 报错，socket 不存在



\`\``

failed to connect to the docker API at unix:///var/run/docker.sock;

dial unix /var/run/docker.sock: connect: no such file or directory

\`\``



\*\*原因\*\*：Docker 守护进程未启动。



\*\*关键点\*\*：



\- Alpine / Nura 用 \*\*OpenRC\*\* → \`rc-service\`

\- Debian / Ubuntu 用 \*\*systemd\*\* → \`systemctl\`



\---



\## 三、解决方案



\### 步骤 1：启动 Docker 守护进程



\#### Alpine / Nura（OpenRC）



\`\``bash

rc-service docker start          # 启动

rc-update add docker default     # 开机自启

rc-service docker status         # 检查状态

docker ps                        # 验证

\`\``



\#### Debian / Ubuntu（systemd）



\`\``bash

systemctl start docker           # 启动

systemctl enable docker          # 开机自启

systemctl status docker          # 检查状态

docker ps                        # 验证

\`\``



\---



\### 步骤 2：写入稳定的镜像源



一键写入 \`/etc/docker/daemon.json\`（两种系统通用）：



\`\``bash

mkdir -p /etc/docker

\[ -f /etc/docker/daemon.json ] && \

  cp /etc/docker/daemon.json /etc/docker/daemon.json.bak.$(date +%s)



cat > /etc/docker/daemon.json <<'EOF'

{

  "registry-mirrors": [

\    "https://docker.1panel.live",

\    "https://docker.m.daocloud.io",

\    "https://hub-mirror.c.163.com",

\    "https://mirror.azure.cn"

  ]

}

EOF

\`\``



写入后重载配置并重启 Docker：



\#### Alpine / Nura（OpenRC）



\`\``bash

rc-service docker restart

\`\``



\#### Debian / Ubuntu（systemd）



\`\``bash

systemctl daemon-reload

systemctl restart docker

\`\``



\*\*验证是否生效\*\*：



\`\``bash

docker info | grep -A 6 "Registry Mirrors"

\`\``



应显示上述 4 个地址，\*\*不含\*\* \`docker.xuanyuan.me\` 和 \`docker.1ms.run\`。



\---



\### 步骤 3：拉取并部署青龙面板



\`\``bash

\# 先测试拉取

docker pull whyour/qinglong:latest



\# 部署（host 网络模式）

docker run -dit \

\--network host \

\--name qinglong \

\--hostname qinglong \

\--restart unless-stopped \

\-v $PWD/ql/data:/ql/data \

  whyour/qinglong:latest

\`\``



\*\*访问地址\*\*：\`http://<服务器IP>:5700\`



\---



\## 四、关键参数说明



\| 参数 | 作用 |

\|---|---|

\| \`--network host\` | 容器复用宿主机网络，\*\*无需 \`-p\` 端口映射\*\* |

\| \`--restart unless-stopped\` | 容器异常退出或重启后自动恢复 |

\| \`-v $PWD/ql/data:/ql/data\` | 数据持久化到宿主机当前目录 |

\| \`--hostname qinglong\` | 设置容器主机名 |



\---



\## 五、OpenRC vs systemd 完整对照表



\| 操作 | OpenRC（Alpine / Nura） | systemd（Debian / Ubuntu） |

\|---|---|---|

\| 启动服务 | \`rc-service docker start\` | \`systemctl start docker\` |

\| 停止服务 | \`rc-service docker stop\` | \`systemctl stop docker\` |

\| 重启服务 | \`rc-service docker restart\` | \`systemctl restart docker\` |

\| 查看状态 | \`rc-service docker status\` | \`systemctl status docker\` |

\| 开机自启 | \`rc-update add docker default\` | \`systemctl enable docker\` |

\| 取消自启 | \`rc-update del docker default\` | \`systemctl disable docker\` |

\| 列出全部服务 | \`rc-service --list\` | \`systemctl list-units --type=service\` |

\| 查看是否自启 | \`rc-update show\` | \`systemctl is-enabled docker\` |

\| 重载配置 | \`rc-service docker restart\` | \`systemctl daemon-reload && systemctl restart docker\` |

\| 查看日志 | \`tail -f /var/log/docker.log\` | \`journalctl -u docker -f\` |

\## 六、如何判断系统用的是哪个



\`\``bash

\# 方法 1：看进程

ps -p 1 -o comm=

\# 输出 "init" 或 "systemd" → systemd

\# 输出 "openrc-init" 或 "busybox" → OpenRC



\# 方法 2：看命令是否存在

command -v systemctl && echo "systemd"

command -v rc-service && echo "OpenRC"

\`\``

\## 七、智能一键脚本（自动识别 OpenRC / systemd）



\`\``bash

\#!/bin/sh

\# 1. 写镜像源

mkdir -p /etc/docker

\[ -f /etc/docker/daemon.json ] && \

  cp /etc/docker/daemon.json /etc/docker/daemon.json.bak.$(date +%s)



cat > /etc/docker/daemon.json <<'EOF'

{

  "registry-mirrors": [

\    "https://docker.1panel.live",

\    "https://docker.m.daocloud.io",

\    "https://hub-mirror.c.163.com",

\    "https://mirror.azure.cn"

  ]

}

EOF



\# 2. 自动识别并重启 Docker

if command -v systemctl >/dev/null 2>&1; then

  echo "\[*] 检测到 systemd"

  systemctl daemon-reload

  systemctl restart docker

  systemctl enable docker

elif command -v rc-service >/dev/null 2>&1; then

  echo "\[*] 检测到 OpenRC"

  rc-service docker restart

  rc-update add docker default

else

  echo "\[!] 未识别的 init 系统，请手动重启 Docker"

fi



\# 3. 验证

docker info | grep -A 6 "Registry Mirrors"

\`\``

\## 八、日志排查速查



\| 日志关键字 | 含义 | 处理方式 |

\|---|---|---|

\| \`403 Forbidden\` | 镜像源拒绝访问 | 从 \`daemon.json\` 移除该源 |

\| \`Host doesn't match\` | 镜像源协议不兼容 | 建议移除 |

\| \`context canceled\` | 拉取被中断 | 重新拉取即可 |

\| \`Daemon shutdown complete\` | Docker 被正常停止 | 用对应命令重启 |

\| \`socket no such file\` | Docker 未运行 | 启动守护进程 |

\| \`Unit docker.service not found\` | 服务未安装 | 检查 Docker 是否安装完整 |



\*\*查看日志的方式\*\*：



\- OpenRC：\`tail -f /var/log/docker.log\`

\- systemd：\`journalctl -u docker -f\`

\## 十一、一句话总结



\> \*\*镜像源要选对，服务管理要认对（OpenRC 用 \`rc-service\`，systemd 用 \`systemctl\`）。\*\*

\> 这两点解决后，青龙部署就是标准的 \`docker run\` 流程。

\## 十二、附：常见 init 系统对照



\| 发行版 | 默认 init | 服务管理命令 |

\|---|---|---|

\| Alpine / Nura / postmarketOS | OpenRC | \`rc-service\` / \`rc-update\` |

\| Debian / Ubuntu / CentOS 7+ | systemd | \`systemctl\` / \`journalctl\` |

\| Arch Linux | systemd | \`systemctl\` |

\| Gentoo | OpenRC（默认） | \`rc-service\` |

\| Void Linux | runit | \`sv\` |

\| Devuan | sysvinit | \`service\` / \`update-rc.d\` |



\> 提示：脚本中判断 \`systemctl\` / \`rc-service\` 是否存在，是最通用、最稳妥的识别方式。
